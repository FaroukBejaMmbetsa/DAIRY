Local setup guide

The exact steps to prepare the database, install the Node packages, start the server, and open the customer interface.

Step 01

Open the project terminal

Open PowerShell in the project folder. Use npm.cmd on Windows because PowerShell may block the npm script wrapper.

cd "C:\Users\Farouk Beja M'mbetsa\OneDrive\Desktop\DAIRY"

Step 02

Install the Node packages

npm.cmd install

This installs Express, MySQL, password hashing, environment variables, and CORS support.

Step 03

Create the environment file

Copy-Item .env.example .env
notepad .env

Set the values in .env. Use your actual MySQL root password. Do not share this file or its password.

DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_actual_mysql_password
DB_NAME=dairy_management
PORT=3000
ADMIN_USERNAME=choose_admin_username
ADMIN_PASSWORD=choose_admin_password

Step 04

Update MySQL Workbench

Open customer_store_schema.sql in MySQL Workbench, make sure the active database is dairy_management, and execute the complete file.

Important: This migration adds tables without deleting your current data. Do not run the full dairy_database.sql file unless you intentionally want to rebuild the database.
USE dairy_management;

The migration adds:

  • products for milk, yoghurt, cheese, and butter
  • orders for customer checkouts
  • order_items for products or cows inside an order
  • payments for future Daraja/M-Pesa records
  • price and available_for_sale to cows

Confirm the tables with:

USE dairy_management;
SHOW TABLES;

Step 05

Start the local server

Run this from the project folder:

npm.cmd start

Wait for this message:

Dairy login server running at http://localhost:3000
Keep this terminal open. Closing it stops the server.

Open the login page

http://localhost:3000/login_page.html

Open the customer storefront directly

http://localhost:3000/customer_dashboard.html

After a successful login, the customer is sent to the dashboard.

Available customer pages

  • customer_dashboard.html - overview and product sections
  • cows.html - cows for sale
  • dairy-products.html - dairy products
  • purchases.html - previous purchases
  • about.html - company and group information

Troubleshooting

Common messages

“npm is not recognized”

Install Node.js LTS, restart VS Code, then use:

node --version
npm.cmd --version

“Cannot find module 'dotenv'”

Install the dependencies from the project folder:

npm.cmd install

“EADDRINUSE :::3000”

The server is already running. Use the existing server and open the URL. If you need to restart it, press Ctrl + C in the terminal running Node, then run:

npm.cmd start

“Access denied for user root”

Open .env and correct DB_PASSWORD. The password must match the MySQL Workbench connection.

“Unable to connect to the server”

Make sure npm.cmd start is running and open the page through http://localhost:3000, not by double-clicking the HTML file.
